# MVP 验收案例

## 使用规则

两个案例都只使用公网信息，不接入企业内部材料。案例文件只提供调研背景和问题，不预先写入事实答案；事实必须由运行时来源和可定位 Evidence 支撑。

## 案例一：海尔智家

- 场景：首次客户技术交流前，售前工程师需要了解家电、全球化运营、AI/数字化变革与近期经营变化。
- 研究问题：
  1. 公司近期经营和业务结构有哪些公开变化？
  2. AI、数字化或智慧家庭相关战略公开落地到哪些环节？
  3. 国内多品牌与海外本土化运营面临哪些公开挑战？
  4. 哪些信息仍需在首次交流中向客户验证？
- PDF 候选：公开年报、半年报或交易所披露文件。
- 人工审阅重点：营收/增长数字、来源网页是否为公司或交易所官方页面、媒体二手转述是否被正确标记。

## 案例二：比亚迪

- 场景：首次新能源与智能制造客户交流前，售前工程师需要了解新能源汽车、储能、海外业务和智能化布局。
- 研究问题：
  1. 比亚迪近期业务、产品或区域扩张有哪些公开变化？
  2. 智能驾驶、数字化制造或能源管理相关能力有哪些公开证据？
  3. 海外市场、供应链和行业竞争有哪些公开风险或变化？
  4. 哪些技术与业务问题需要在首次交流中进一步确认？
- PDF 候选：公开年报、社会责任报告、交易所披露或正式技术白皮书。
- 人工审阅重点：车型/销量/区域数字、技术能力与营销表述的边界、官网与媒体来源等级差异。

## MVP 通过条件

每个案例都必须：

1. 在 30 分钟控制预算内生成 HTML 和 Markdown；
2. 每个研究问题获得搜索机会；
3. 至少一个公开来源成功摄取，至少一个公开 PDF 成功经 MinerU API 解析；
4. 所有 Fact 都有可定位 Evidence，来源网页可直接打开；
5. 二手来源明确显示“二手来源，待官方验证”，未确认来源显示“来源等级未确认”；
6. 失败来源、信息缺口和人工待确认项完整披露。
