# 内容可信度修复与验收

## 实现范围

1. `ingestion/extractor.py`：在 Trafilatura 前显式解码。优先 BOM、严格 UTF-8，再尝试白名单中的页面编码声明；无法可靠确定时返回 `TEXT_ENCODING_UNCERTAIN`。不采用替换字符容错解码。
2. `ingestion/text_quality.py`：拒绝替换字符、异常控制字符和此次混杂大小写西里尔乱码模式。HTML、PDF 和持久化正文块都检查，损坏正文不能进入模型。该检查是保守启发式，不声称识别所有乱码。
3. `SourceRevision` 保存编码和明确的 HTML 发布日期；字段可空，兼容历史实体。只读取指定发布日期 meta，不把正文事件日期、URL 日期或抓取时间冒充发布日期。PDF 没有可靠发布日期时保持未知。
4. 报告保留通过原文和语义核验的陈述及血缘，但统一标注“来源陈述，待人工核实”，展示发布日期或未知。只有引用完整、一手来源、发布日期距报告日期不超过 365 天且没有相对时间或计划表达的内容进入当前摘要。365 天为本轮保守默认规则，并不保证资料仍有效。
5. 全覆盖但仍有陈述不满足摘要约束时，终态为 `NEEDS_REVIEW`；来源失败或问题覆盖不足仍为 `PARTIAL`。Claim 的 APPROVED 表示证据与语义门禁通过，不代表外部事实已被独立证实。
